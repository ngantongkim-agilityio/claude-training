## Deploy notes

- Breaking API change (#38, KAN-6): `PATCH /invoices/:id` (v1 and v2) now requires `expectedUpdatedAt` to approve or reject. Deploy the API and web app together, since the web app sends it only from #39 (KAN-7).
- #32: create the `claude-review` environment (deployment branches: `main` only), move `CLAUDE_CODE_OAUTH_TOKEN` into it, and delete the repository secret.
- #40: `start` and `worker:report-email` depend on `build`, so a host that builds and starts separately must run `pnpm build` first. Check the env vars in `globalEnv` against the deploy target.
- #41: the repository owner applies the `v*` tag ruleset after AC-2 and AC-8 pass.
- #11: local clones that ran `pnpm install` before still have `core.hooksPath=.husky/_`. Run `git config --unset core.hooksPath` and remove the `.husky/` directory.
